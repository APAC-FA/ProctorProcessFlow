Process Flows

Process Flows and Escalation Procedures

How to Use This Guide

Follow the steps in order. Check the test taker's situation, choose the correct YES or NO path, and follow the instructions.

Important: Follow the applicable exam policy and CS/Manager on Duty instructions. Do not manually cancel or END a session unless authorized by the applicable process.

1. Test Taker Does Not Have a Valid Government-Issued ID

Use when the test taker has no valid physical government-issued ID or presents an expired ID.

STEP 1: Ask for another valid physical government-issued ID.
Message to Test Taker Please provide another valid government-issued ID. You must present a valid physical government-issued ID to test today.

YES — Has a Valid ID

Continue with the required check-in process.

NO — No Valid ID

Proceed to Step 2.
↓
STEP 2: Explain the cancellation and ask for confirmation.
Message to Test Taker If you do not have one available, please contact support@certiverse.com for further assistance. Unfortunately, we will need to cancel this session. Please confirm.

STEP 3: After the Test Taker Confirms

  1. Take a screenshot of the chat history. Hide all personally identifiable information (PII).
  2. Cancel the session using the appropriate reason from the dropdown, following the applicable cancellation procedure.
  3. Post the session details in the APAC Team GC.
  4. Follow the required Proctor Hub closure procedure.

APAC Team GC Format

Test Taker Initial (Reservation Code) Exam Name and Code Reason | Exam Time

2. Name on ID Does Not Match the Reservation

Use when the name on the ID is misspelled or differs from the name on the exam reservation.

STEP 1: Ask whether the test taker has another valid ID.
Message to Test Taker Do you have another valid government-issued ID?

YES — Has Another ID

Check the other ID. If the name matches the reservation and all requirements are met, continue check-in.

NO — No Other ID

Proceed to Step 2.
↓
STEP 2: Open the Name-Change Policy tab.

Check whether the client's exam policy allows a name change.

YES — Name Change Allowed

  1. Send the name-change message below.
  2. Notify CS of the name-change request.
  3. Wait for confirmation that the change is complete.
  4. Refresh the dashboard and verify the updated name.
  5. Inform the test taker and continue only when the requirements are met.

NO — Name Change Not Allowed

  1. Send the cancellation message below.
  2. Ask the test taker to confirm.
  3. Take a screenshot with all PII hidden.
  4. Request manual cancellation from CS or the Manager on Duty.
Message — Name Change Allowed Unfortunately, that is not the name registered for this reservation. Per Certiverse rules, the name on your ID must fully match the exam reservation. To request a name change, please contact support@certiverse.com.
Message — Name Change Not Allowed Unfortunately, we will need to cancel this session. Please email support@certiverse.com for assistance with rescheduling. Please confirm.

STEP 3: Report and Close

  1. Notify CS and follow the instructions provided by CS or the Manager on Duty.
  2. Post the session details in the APAC Team GC.
  3. Close the session in Proctor Hub only when authorized.

APAC Team GC Format

Test Taker Initial (Reservation Code) Exam Name and Code Reason | Exam Time

3. Candidate Is Not in a Private Testing Area

Use when the test taker cannot remain in a private testing area for the entire exam.

STEP 1: Confirm that the test taker can stay in a private testing area.
Message to Test Taker You are required to be in a private testing area for the entire duration of the exam.

YES — Can Use a Private Area

Continue with the required check-in process.

NO — Cannot Use a Private Area

Proceed to Step 2.
↓
STEP 2: Explain cancellation and request confirmation.
Message to Test Taker Unfortunately, we will need to cancel this session. Please email support@certiverse.com for further assistance with rescheduling. Please confirm.

STEP 3: After Confirmation

  1. Send: Thank you! You may close this session now.
  2. Notify CS or the Manager on Duty and request manual cancellation.
  3. Keep the session open in Proctor Hub while waiting for confirmation and instructions.
  4. Document all actions taken and relevant details.
  5. Follow the instructions from CS/Manager on Duty before closing the Hub session.
  6. Post the session details in the APAC Team GC.

4. Candidate Disconnects After the Exam Is Released

Use when the candidate disconnects and does not immediately reconnect.

STEP 1: Wait up to 20 minutes for the candidate to reconnect.

YES — Candidate Reconnects

Continue the exam as required.

NO — Candidate Does Not Return

Notify CS and document all actions.

STEP 2: Notify Client Support

Test Taker / Exam Code: Concern: Request:

Follow the guidance provided by CS.

STEP 3: Follow the Correct Path

If CS Confirms the Session Should End

END the session using the reason provided by CS.

If AI-Assisted and There Is No Contact

If there is still no contact from the candidate or Support, keep the session open in Proctor Hub until the exam duration has ended. Then remove or close the session from Proctor Hub.

5. Recurring Screen-Sharing Disconnections

Use when screen sharing repeatedly stops during the exam.

STEP 1: Ask the test taker to refresh the browser.
Message to Test Taker We are no longer able to hear or see you. Please refresh your browser and ensure your camera, microphone, and screen are being shared properly.

Issue Fixed

Proceed with or resume the exam.

Issue Continues

Proceed to Step 2.
↓
STEP 2: Relaunch the session.

Ask the test taker to use another supported browser and ensure no external monitors are connected.

Message to Test Taker It seems you are experiencing issues with your session. Please close this browser and relaunch your session from the exam dashboard.

Issue Fixed

Proceed with or resume the exam.

Issue Continues

Send the warning message below.

STEP 3: Send a Warning

Warning Message We have noticed that your screen sharing has stopped multiple times. Please be advised that if this happens again, we may need to end your exam. Maintaining exam integrity is important to us.

STEP 4: If the Issue Happens Again

  1. Document all actions taken and troubleshooting steps completed.
  2. Notify CS using the template below.
  3. Wait for CS confirmation before ending the session.
  4. If CS confirms, END the session using the reason provided by CS.
  5. Post the session details in the APAC Team GC.

Message to CS

Test Taker / Exam Code: Issue: Troubleshooting steps completed:
