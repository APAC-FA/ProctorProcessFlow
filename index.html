1. Test Taker Does Not Have a Valid Government-Issued ID

Purpose

To guide proctors in handling test takers who cannot provide a valid government-issued ID or present an expired ID.

Scope

Applies when a test taker cannot provide a valid physical government-issued ID required for the exam.

Step 1 — Request another valid ID

Please provide another valid government-issued ID. You must present a valid physical government-issued ID to test today.
  • If yes: The test taker provides another valid ID. Continue with the required check-in process.
  • If no: Proceed to Step 2.

Step 2 — Inform the test taker and request confirmation

If you do not have another valid ID available, please contact support@certiverse.com for further assistance. Unfortunately, we will need to cancel this session. Please confirm.

Step 3 — Capture the chat history

Take a screenshot of the chat history. Ensure all personally identifiable information (PII) is hidden.

Step 4 — Cancel the session

Once the test taker confirms, cancel the session using the appropriate cancellation reason from the dropdown.

Step 5 — Document and close

Post the session details in the APAC Team GC using the standard reporting format in Section 6. Then close the session in Proctor Hub, in accordance with the applicable procedure.

2. Name on ID Does Not Match the Reservation

Purpose

To guide proctors in handling discrepancies between the name on the test taker’s government-issued ID and the name on the exam reservation.

Scope

Applies when the name on the ID is misspelled, incorrect, or does not match the reservation.
StepActionInstructions
1Request another IDAsk: “Do you have another valid government-issued ID?” If another valid ID matches the reservation, continue check-in. Otherwise, proceed to Step 2.
2Check the Name-Change PolicyReview the Name-Change Policy tab to determine whether the client permits a name change.
3AName change permittedSend the message below, notify CS of the request, and follow the approved name-change process.
3BName change not permittedInform the test taker that the session must be canceled and request confirmation. Then proceed with the applicable cancellation process.
4Capture chat historyTake a screenshot and ensure all PII is hidden.
5Complete the actionFor a name change, refresh the dashboard after CS confirms completion and inform the test taker. For cancellation, request manual cancellation from CS or the Manager on Duty, as applicable.
6Document and closePost the required details in the APAC Team GC and close the session in Proctor Hub according to the applicable procedure.

Message — Name change permitted

Unfortunately, the name on your ID does not match the name registered for this reservation. Per Certiverse rules, the name on your ID must fully match the exam reservation. Please contact support@certiverse.com to request a name change.

Message — Name change not permitted

Unfortunately, we will need to cancel this session. Please contact support@certiverse.com for further assistance with rescheduling. Please confirm.

Important: Do not proceed with the exam until the name discrepancy is resolved in accordance with the client’s policy.

3. Candidate Is Not in a Private Testing Area

Purpose

To guide proctors in handling test takers who cannot remain in a private testing area throughout the exam.

Scope

Applies when the test taker cannot meet the private testing area requirement for the entire exam.

Step 1 — Confirm the testing area

You are required to be in a private testing area for the entire duration of the exam.
  • If yes: The test taker can remain in a private testing area. Continue check-in.
  • If no: Proceed to Step 2.

Step 2 — Request cancellation confirmation

Unfortunately, we will need to cancel this session. Please email support@certiverse.com for further assistance with rescheduling. Please confirm.

Once the test taker confirms, send:

Thank you! You may close this session now.

Step 3 — Notify Client Support

A manual cancellation must be handled by CS or the Manager on Duty. Notify CS using this template:
Test Taker / Exam Code: Concern: Unable to provide a private testing area. Request: Please review and process the manual cancellation.

Step 4 — Document and close

  • Document all actions taken and relevant details.
  • Follow the guidance provided by CS or the Manager on Duty.
  • Post the session details in the APAC Team GC using the standard reporting format in Section 6.
  • Close the session in Proctor Hub according to CS/PM instructions.

4. Candidate Disconnects After the Exam Has Been Released

Purpose

To provide steps for handling candidates who disconnect after their exam has been released and do not immediately reconnect.

Scope

Applies when a candidate disconnects after exam release and does not immediately return to the session.
StepSituationRequired action
1Candidate disconnectsWait up to 20 minutes for the candidate to reconnect.
2ACandidate reconnects within 20 minutesContinue the exam as required.
2BCandidate does not reconnect within 20 minutesNotify CS using the template below. Document all actions taken and relevant details.
3CS confirms the session should endEnd the session using the reason provided by CS.
4AI-Assisted session; no contact from candidate or SupportKeep the session open in Proctor Hub until the exam duration ends. Once the duration has ended, remove or close the session in Proctor Hub.

CS notification template

Test Taker / Exam Code: Concern: Candidate disconnected after exam release and did not reconnect within 20 minutes. Request: Please review the session and advise on the next steps.

Important: Do not end the session without CS confirmation when confirmation is required by the applicable procedure. Follow the reason and instructions provided by CS.

5. Recurring Screen-Sharing Disconnections

Purpose

To guide proctors in troubleshooting repeated screen-sharing disconnections and escalating persistent technical issues.

Scope

Applies when a candidate repeatedly loses screen sharing, camera, or microphone connectivity during an exam.

Step 1 — Ask the test taker to refresh the browser

We are no longer able to hear or see you. Please refresh your browser and ensure your camera, microphone, and screen are being shared properly.
  • If resolved: Proceed with or resume the exam.
  • If the issue persists: Proceed to Step 2.

Step 2 — Ask the test taker to relaunch the session

Ask the test taker to close the current browser and relaunch the session from the exam dashboard using another supported browser. Ensure no external monitors are connected.

It seems you are experiencing issues with your session. Can you please close this browser and relaunch your session from the exam dashboard?
  • If resolved: Proceed with or resume the exam.
  • If the issue persists: Proceed to Step 3.

Step 3 — Send a warning

We have noticed that your screen sharing has stopped multiple times. Please be advised that if this happens again, we may need to end your exam. Maintaining exam integrity is important to us.

If the issue continues, proceed to Step 4.

Step 4 — Document and escalate to CS

Document all troubleshooting steps and notify CS using this template:
Test Taker / Exam Code: Issue: Recurring screen-sharing disconnections. Troubleshooting steps completed: - Browser refresh - Relaunched session using another supported browser - Checked external monitor connections

Step 5 — Follow CS instructions

  • If CS confirms that the session should end, end the session using the reason provided by CS.
  • Post the required session details in the APAC Team GC using the standard reporting format in Section 6.
  • Follow the applicable Proctor Hub closing procedure.

6. Standard APAC Team GC Reporting Format

Use this format for session cancellations and technical incidents where APAC Team GC reporting is required.

Test Taker Initial (Reservation Code) Exam Name and Code Reason | Exam Time

Example

A (8A8-D3F) HashiCorp Certified: Terraform Associate (004) Reason for cancellation | 01:00 PM

For recurring technical issues, use an appropriate reason, such as: “Test taker technical issue | 01:00 PM.”
